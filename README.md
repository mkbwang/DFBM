# Nonparametric Denoising

* `tune.bmfsvt` in R/bmfsvt.R is the latest binary matrix factorization algorithm. `R/svt_utils.R` contains some relevant utility functions.
* `logisticcf.R` and `utils.R` contains codes for the old methods.
* `experiment/01_accuracy.R` and other scripts in `experiment/R` contains the codes for the experiment tailored for evaluating the accuracy of probability recovery with binary matrix factorization algorithms.
